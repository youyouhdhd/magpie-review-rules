自动模式审核

只改变操作审核请求的模型。普通对话继续使用 Desktop 中选择的模型。

首次安装默认不固定审核模型，也不添加兼容规则。请先选择能返回 Claude 判定格式的模型，再保存配置。

模型兼容规则

为第三方别名指定实际的 Claude 规则；命中多条时按显示顺序执行。

规则绑定具体供应商的模型。使用路由组时，会按实际回答的模型匹配；Claude 预设适用于 Anthropic Messages 接口。

没有兼容规则。可保留固定审核模型，单独使用这一功能。

自定义规则怎样运行？

选择目标模型后，JavaScript 在请求路由到该模型时运行。可修改 body，也可返回新的请求对象。ctx 提供 agent、protocol、provider、model、review；ctx.review 表示操作审核请求。

代码在 Magpie 的 JavaScript 沙箱中运行，不能访问网络或本地文件。单次规则有 250 ms 时限；运行异常或超时按 Magpie 的机制保留原请求，并记录到插件状态。
